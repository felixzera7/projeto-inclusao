# 🚀 Codificar para Incluir e Evoluir

Projeto prático desenvolvido como requisito para a disciplina de **Atividade Extensionista II - Tecnologia Aplicada à Inclusão Digital**, do curso de Análise e Desenvolvimento de Sistemas (ADS) da **UNINTER**.

## 🎯 Objetivo
Promover a inclusão digital e a capacitação técnica para a comunidade do bairro Parque Viana (Barueri - SP). A plataforma oferece um ambiente de aprendizagem intuitivo, gratuito e acessível, servindo como porta de entrada para o mercado de trabalho e para a área da tecnologia.

## 📚 Módulos Disponíveis
*   **Lógica de Programação:** Fundamentos de algoritmos, variáveis, operadores e estruturas condicionais.
*   **Microsoft Word:** Intensivão para criação e formatação de documentos e currículos.
*   **Microsoft Excel:** Guia completo de planilhas, fórmulas essenciais e organização de dados.
*   **Avaliação de Impacto:** Formulário integrado para recolha de feedback real dos utilizadores da comunidade.

## 💻 Tecnologias Utilizadas
*   **HTML5 & CSS3:** Estruturação semântica e estilização minimalista/responsiva.
*   **JavaScript (Vanilla):** Lógica de navegação dinâmica (Single Page Application) sem recarregar a página.
*   **GitHub Pages:** Hospedagem e distribuição do projeto.
